Exact-source continuity preparation
===================================

The source includes the closed exact-source continuity owner protocol accepted
with contract digest
``79e60cf49b93e9f947c284e35cffd316f7994a75827de495f626bb7beff76a9c``.
It is separate from custody checkpoints and ordinary catalogue object CAS.
An authenticated application certificate does not authorize this new purpose.

The continuity endpoint currently returns unavailable. It does not read a
continuity binding, contact AWS, modify a catalogue, or provision a service.
The existing application listener has not been qualified for the continuity
protocol's installed-origin and total-deadline requirements.

Before operational admission, the operating owner must qualify the independent
external namespace, immutable version and legal-hold policy, original enrollment,
current installed binding, purpose-specific peer admission and native transport.
The source's private owner adapter requires fresh complete external history;
local snapshots, public hashes and local catalogue versions cannot replace it.
Restoring producer and catalogue snapshots must not restore the external root.

Conditional append reservations are irreversible. Losing readback or an
acknowledgement does not delete a reservation or authorize another effect.
An exact original retry reconciles the occupied sequence before checking an
advanced head; a changed original conflicts. Producer crash and effect-start
decisions remain owned by Proxenos under the accepted sole-sequencer contract.

No installation, backend credentials, budget, operational trust, release lockset
or completed INT-07 acceptance is implied by this source preparation. Its Kanon
source companion is PR 741.
